How FreJun Teler One-Click Calling Works

1. Outbound Dial: Clicking Call Now issues a POST /api/calls to the Express backend, which calls FreJun Teler API (POST /api/v1/voice/calls/initiate) with authenticated X-API-Key.

2. Call Flow Handshake: Teler dials the destination number. When callee answers, Teler POSTs to your flow_url. The server responds within 5s with an action:

  • play: Streams audio file (greeting/announcement) and hangs up.
  • dial: Bridges caller to an agent phone (two-way conversation).
  • stream: Opens bidirectional WebSocket for AI voice agent.

3. HMAC Signature Verification: Status webhooks (call.initiated, call.answered, call.completed) sent to status_callback_url are verified using HMAC-SHA256 with X-Teler-Signature and X-Teler-Timestamp headers.

4. Deduplication Guard: Built-in in-flight cooldown prevents accidental double-dialing of the same lead from Hashtagg CRM.
